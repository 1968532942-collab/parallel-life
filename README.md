# 如果那天，我选择了另一条路 · 第一人称互动叙事 H5（4.0）

一封来自平行时空的信，两条人生路线：家乡线五幕、远方线六幕，各自的结局与海报，以及统一终章。
纯前端实现，**无任何外部依赖、无网络请求**，可离线运行。

## 一、快速体验

| 方式 | 做法 |
| --- | --- |
| 本地直接打开 | 双击 `index.html`（多文件版）或 `dist/index.html`（单文件版）即可 |
| 本地服务器（推荐调试用） | 在项目目录运行 `python3 -m http.server 8080`，浏览器打开 `http://localhost:8080` |
| 手机预览 | 部署到公网后用手机浏览器打开（见第四节） |

首次体验约 5–8 分钟。右上角 ♪ 为声音开关，☰ 菜单可回到分岔路口、直接体验任一路线或清除进度。进度按“幕”自动保存在本机浏览器，下次打开可从上次的幕继续。

## 二、项目结构

```
index.html            页面骨架（文案面板、菜单、海报弹窗、加载提示）
css/style.css         布局、文案面板、互动提示、通用动画（树冠摆动、飘落、行走）
css/scenes.css        各场景的状态动画（由 .f-xxx 状态标记驱动）
js/story.js           全部剧情数据：每幕的镜头、文案、互动、状态（与渲染分离）
js/engine.js          状态机：镜头推拉、逐段文案、互动系统、存档、结局与终章
js/scenes-common.js   场景工具 + 标题页 / 序章（信封、分岔路）/ 终章
js/scenes-home.js     家乡线五幕 + 点灯人结局
js/scenes-far.js      远方线六幕 + 逐光者结局（出租屋两幕共用同一房型）
js/figures.js         人物、手部、主角背影、年轻的自己（程序绘制 SVG）
js/audio.js           Web Audio 实时合成的全部音效与原创旋律
js/poster.js          1080×1920 结局海报（Canvas 本地绘制）
js/heroine.js         主角参考图（用户提供，裁切压缩后内嵌）
dist/                 打包版（tools/build.py 生成）：index.html 为单文件代码，背景音乐在 dist/music/
music/                背景音乐（AAC），文件名即场景编号
video/                场景视频（720p H.264，约 11MB）：家人散步、校门、面馆、音乐厅大堂、音乐会、夜宵碰杯、两个结局。视频开始播放后才淡入盖住同构图的插画；播放失败时自动显示插画
art/                  场景插画（WebP，用户用 AI 生成）：背景、透明素材（手、人物、行李箱、面碗、咖啡杯等）
js/scenes-art.js      插画版场景：把 art/ 里的图片按原比例铺满画面，互动点按图片百分比定位
css/art.css           插画版场景的动画（推门、开灯、地铁窗外流动、追光等）
js/music.js           背景音乐播放器（交叉淡化、循环、开关）
js/music-map.js       场景与音乐文件的对应表
tools/build.py        打包脚本：python3 tools/build.py
tools/playthrough.py  自动走通测试：python3 tools/playthrough.py home 输出目录
```

### 修改剧情
只改 `js/story.js`。每一“拍”（beat）可以设置：`shot` 切换镜头、`cam: [焦点x%, 焦点y%, 缩放]` 推拉镜头、`add/rm` 场景状态、`lines` 文案、`act` 互动（`tap` 点击 / `hold` 长按 / `swipe` 滑动 / `drag` 拖动 / `pan` 左右探索 / `choice` 选择）。

## 三、素材来源说明（如实列出）

| 素材 | 来源 | 状态 |
| --- | --- | --- |
| 主角正面形象 | 用户上传的参考图，裁切为 WebP 内嵌 | 已完成（标题页、地铁车窗倒影） |
| 主角背影、年轻的自己、家人、学生、朋友、路人 | 按参考图的配色与“无五官纸艺”画风，用 SVG 程序绘制 | 已完成 |
| 全部场景（老街、校门、面馆、樱花大道、超市、出租屋、地铁、音乐厅、美术馆、咖啡馆、夜宵店、夜景） | SVG 程序绘制 + Canvas 生成的纸张肌理 | 已完成 |
| 背景音乐 | 用户提供的 11 首古典钢琴配乐，截取前 3 分钟、统一响度并压缩为 AAC（music/，共约 17MB）；对应关系见 js/music-map.js。每幕一首，切换时 2 秒交叉淡化，音量 20%，循环播放；某首加载失败时自动退回程序合成的背景乐 | 已完成 |
| 音效 | Web Audio 实时合成（翻信纸、铃声、地铁提示音、碰杯等），无外部音频 | 已完成 |
| 字体 | 使用设备自带中文字体（宋体/苹方等），不加载外部字体 | — |
| 结局海报 | 运行时用 Canvas 绘制 | 已完成 |

**插画版（当前）：** 场景已换成用户用 AI 生成的 42 张水彩插画（art/，约 8MB）。旧的程序绘制版仍保留在 scenes-home.js / scenes-far.js 中，删掉 index.html 里的 scenes-art.js 一行即可切回。

**旧版说明：** 当前画面是“扁平纸艺 + 纸张肌理”的程序绘制风格，不是真正手绘水彩。如果想达到手绘水彩动画电影的质感，需要另外绘制分层插画（每个场景的背景、中景、前景分层 PNG），可以直接替换对应场景函数里的 SVG，互动与镜头逻辑不需要改。建议优先替换的画面：桂花老街、校门与高中闪回、樱花大道、出租屋（两幕共用）、音乐厅、两个结局画面。

## 四、公网部署

整个项目是静态文件，任何静态托管都可以：

- **GitHub Pages**：把项目文件放进仓库根目录，Settings → Pages → Deploy from a branch → `main` / `/(root)`。地址形如 `https://用户名.github.io/仓库名/`。国内访问可能不稳定。
- **腾讯云 CloudBase 静态网站托管**（国内访问更稳定）：上传整个项目目录或 `dist/index.html`，使用分配的默认域名，或绑定已备案的自有域名。
- 只想发一个文件：使用 `dist/index.html`，它包含全部代码与图片。

## 六、兼容与降级

- 适配 iPhone / 安卓竖屏与桌面浏览器（桌面以手机比例居中显示）；小屏（高度 ≤ 700px）自动压缩文案行距与结局布局。
- 声音需在点击“打开那封信”后才会启动（浏览器限制）；不支持 Web Audio 时静默运行。
- 浏览器不允许直接下载时，海报以图片预览显示，可长按保存。
- 系统开启“减少动态效果”时，自动关闭循环动画。
